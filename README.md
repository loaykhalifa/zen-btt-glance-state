# Zen BTT Glance State

A Sine userChrome JavaScript mod for Zen Browser.

It synchronizes the selected tab state with the BetterTouchTool string variable `zen_tab_type`.

- `GLANCE` when the selected tab is a Zen Glance tab
- `NORMAL` otherwise

## Requirements

- Zen Browser
- Sine with unsafe JavaScript mods enabled
- BetterTouchTool

## Installation

Paste `loaykhalifa/zen-btt-glance-state` into Sine.
